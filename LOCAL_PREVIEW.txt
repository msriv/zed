Build from this checkout with the already installed toolchain/cache:
  source ~/.cargo/env
  PATH=/opt/homebrew/bin:$PATH \
  LK_CUSTOM_WEBRTC="$PWD/target/native-deps/mac-arm64-release" \
  CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_DEV_BUILD_OVERRIDE_DEBUG=0 \
  CARGO_INCREMENTAL=0 CARGO_BUILD_JOBS=4 cargo build -p zed --bin zed

The cached native dependency is the upstream WebRTC release webrtc-0001d84-4,
mac-arm64-release, verified against GitHub's published archive SHA-256:
09ba71bfbc15c6aacced7fe20451a9648dfe648c24295f28d75fc386dbd7281a.
The build command assumes that cache remains present; cargo clean removes it.
Rebuilding does not automatically replace the copied executable in the app.

To capture the native conversation fixture, use the same build environment with:
  VISUAL_TEST_FILTER=agent_conversation_redesign \
  VISUAL_TEST_OUTPUT_DIR=target/visual_tests \
  cargo run -p zed --bin zed_visual_test_runner --features visual-tests
The runner requires macOS window-server access. To intentionally refresh the
local ignored baselines, add UPDATE_BASELINE=1 after reviewing the layout.

Detailed temporary validation logs are under /private/tmp/zed-*.log.

Appearance preset

LOCAL_APPEARANCE.json preserves the frosted light/dark theme overrides, UI,
editor and terminal fonts, and panel layout used by the local Zed installation.
These are user settings, separate from the compiled Agent Panel redesign.
To reproduce the appearance, open Zed's user settings and merge the preset's
top-level keys into the existing object. Back up your settings first; do not
replace the whole file, since other preferences and integrations live there.
The preset is not automatically loaded by building this fork.

The fonts .SystemUIFont and SFMono-Regular are macOS-specific; other platforms
may need installed equivalents. Font binaries are not included. Frosted blur
depends on platform support and operating-system transparency settings.
